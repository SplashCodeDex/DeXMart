## Summary

## Context

DeXMart uses a unified Next.js dashboard as the sole interface for B2C users. The current frontend suffers from a large number of TypeScript errors ranging from implicit 'any' types to missing protocol definitions. These errors hinder development and may hide logic bugs.

## Problem Description

Running `pnpm typecheck` in the `frontend` directory reveals 94 errors.
Categories of errors identified:

- **Missing/Incorrect Types**: `JsonSchema`, `ChatMessage`, `ExecApprovalsFile`, `PendingRequest` are not properly imported or defined.
- **Implicit any**: Parameters in `.map` callbacks and state setters lack explicit types.
- **Null/Undefined Risks**: Missing guards for potentially null/undefined objects (e.g., `rpc`, `target[parts[i]]`).
- **Property Mismatches**: Incorrect usage of Zod errors, missing properties in cron payloads, and protocol schema mismatches.
- **Module Resolution**: Issues with `@openclaw/protocol` exports and `.ts` extension imports in ESM.
